# 🧠 DSA-AI-Assistant

An **AI-powered DSA learning assistant** built with **Spring Boot & Spring AI** to help you learn, understand, and practice Data Structures & Algorithms.

### 🛠 Tech Stack

**Java 21 · Spring Boot · Spring AI · OpenAI · JPA · PostgreSQL/H2 · Maven · Lombok**

### 🚀 Setup

```bash
export SPRING_AI_OPENAI_API_KEY=your_api_key
mvn clean package
mvn spring-boot:run
```

### 🧪 API Testing

Test the APIs using:

* `test-chat.http`
* `test-progress.http`

Works with **VS Code REST **
